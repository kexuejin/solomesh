# PWA Icons

## 自动生成

图标通过 `npm run generate-icons` 自动生成。构建时会自动运行此脚本。

稳定源文件：`logo-1024.png`。
脚本会生成全部 PNG 图标和 `public/favicon.svg`。

## 图标规格

- `icon-48.png`
- `icon-72.png`
- `icon-96.png`
- `icon-128.png`
- `icon-144.png`
- `icon-152.png`
- `icon-192.png`
- `icon-384.png`
- `icon-512.png`
- `icon-512-maskable.png`
- `apple-touch-icon-180.png`
- `public/favicon.svg`

## 自定义图标

如需更新图标：

1. 直接替换 `logo-1024.png`
2. 运行 `npm run generate-icons`
